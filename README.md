# PasteToPlay

VR video player for Meta Quest. Paste a link, it just plays.

🌐 [pastetoplay.app](https://pastetoplay.app) · 🛒 [Meta Horizon Store](https://www.meta.com/experiences/pastetoplay-180360-vr-video-player/1231909206675936/)

## What it does

- Paste a video URL from the Quest clipboard, or type one with the in-app keyboard
- Auto-detects flat, VR180, 360, SBS, TB, and dual-fisheye from the actual video frames
- DLNA browsing from media servers on your local network
- Native ExoPlayer decoding: MP4, HLS, DASH, SmoothStreaming
- Resume playback for direct links and DLNA
- No accounts, no analytics, no server

## This repo

GitHub Pages source for [pastetoplay.app](https://pastetoplay.app). The app itself is developed in a private repo.
